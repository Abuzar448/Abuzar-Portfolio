#🚀 Animated Interactive Portfolio - Abuzar Khan .

A high-performance, fully responsive personal portfolio featuring smooth horizontal animations and modern UI components. This project showcases my journey as a Full-Stack Developer and AI Engineering enthusiast.

🌐 Live Demo
https://abuzar-portfolio-jet.vercel.app/

✨ Key Features
Modern Interactive UI: Built using Aceternity UI & Magic UI components for a premium look and feel.

Horizontal Scroll Experience: A unique navigation flow implemented with Framer Motion for smooth transitions between sections.

Advanced Animations: Eye-catching entrance and scroll-triggered animations that enhance user engagement.

Fully Responsive: Specifically optimized for every device size (Mobile, Tablet, Desktop) with custom layout organization.

Mobile-First Navigation: Features a sleek Bottom Navbar for easy thumb-access on mobile devices.

Direct Mail Integration: Functional contact form that allows users to send messages directly to my email.

📂 Sections Included
🏠 Home: Introduction with a dynamic hero section.

👤 About: My background and journey in Computer Science.

🎓 Education: Academic details from B.Tech (CSE) and earlier.

💻 Projects: Showcase of my work with live demo links and GitHub repos.

🛠️ Skills: Technical expertise in MERN Stack, Python, and AI tools.

📜 Certifications: Professional validations and achievements.

📞 Contact: Integrated messaging system for networking.

🛠️ Tech Stack
Frontend: React.js

Animation: Framer Motion

Icons: React Icons

UI Components: Aceternity UI, Magic UI, Tailwind CSS

Communication: EmailJS .

🧠 Technical Challenges & Solutions
- **Responsive Animations:** Fixing Framer Motion behaviors for mobile touch-screens to ensure horizontal scroll doesn't break.
- **Component Reusability:** Designing modular React components to keep the codebase DRY (Don't Repeat Yourself).
- **Performance Optimization:** Optimizing heavy animations from Aceternity UI to maintain a 60FPS experience.
